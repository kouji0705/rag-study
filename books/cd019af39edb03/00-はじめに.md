# はじめに

RAGには、Naive RAG、Reranking RAG、Corrective RAG、Multi-hop RAGなど、さまざまな手法があります。

それぞれ何が違い、どんな場面で役立つのでしょうか？

本書では、**RAGを一つずつ実装・検証し、その仕組みと使いどころを理解すること**を目指します。

## この本で大切にすること

TypeScriptの実装方法そのものより、**LLMやJevをどのように活用するか**を重視します。

```mermaid
flowchart LR
    A["課題を見つける"] --> B["LLM・Jevに依頼"]
    B --> C["レスポンスを確認"]
    C --> D["処理と回答を比較"]
    D --> E["結果を考察"]
```

実際のリクエスト・レスポンスを紹介し、AIの判断によって処理や回答がどう変わるのかを確認します。

うまく動いた結果だけでなく、失敗した結果も取り上げます。

## 共通の題材

架空のBtoB SaaS「TaskFlow」のマニュアルを使用します。

例えば、こんな質問です。

> Standardプランを月の途中で解約したら、日割りになりますか？

マニュアルを検索し、必要に応じてJevで評価・判断し、LLMで回答します。

実装にはTypeScript、OpenRouter、Jev、Chromaを使用します。

## 本書の構成

| パート | 学ぶこと |
|---|---|
| 第1部：RAGの基礎（第1〜5章） | RAGの仕組み、Embedding、ベクトルDB |
| 第2部：検索の改善（第6〜9章） | Naive RAG、Reranking、Filtering |
| 第3部：判断と探索（第10〜14章） | Adaptive、Corrective、DecisionRAG、Multi-hop |
| 第4部：応用と総括（第15〜17章） | 関係探索、方式の比較、使い分け |

最初から順番に学ぶことも、興味のあるRAGの章から読むこともできます。

各章では、仕組み・実験・結果・考察をできるだけ独立して理解できるようにしています。

**RAGの手法を知るだけでなく、課題に応じて使い分けられるようになること。**

それが本書のゴールです。
